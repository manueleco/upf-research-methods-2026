# Aplicación de los materiales al curso

Information sources, diapositivas 4 y 7: cada lectura debe producir un resumen, una valoración y datos bibliográficos. La revisión debe organizarse alrededor de conceptos y de las preguntas de investigación. Usar la matriz de literatura para conectar cada referencia con una afirmación del borrador.

Reality and consensus, diapositivas 3–5: evaluar credibilidad, relevancia y calidad de las fuentes; una fuente alojada en una biblioteca o en internet no basta para garantizar verdad. Aplicarlo a fuentes obtenidas por herramientas IA y contrastar las referencias originales.

MERE, diapositivas 3–4: meta-investigación estudia métodos, comunicación, reproducibilidad, evaluación e incentivos de la investigación. Las instrucciones distinguen este propósito de un metaanálisis y de una revisión sistemática. Elegir una pregunta sobre el proceso de investigar, no solamente sobre un resultado de tu disciplina.

MERE sesión 2, diapositiva 6: se espera realizar un pequeño estudio/experimento, escribir y enviar un paper, revisar trabajos de compañeros, mejorarlo y presentarlo. Diseñar un método ejecutable antes de redactar promesas.

Propuesta opcional para un tema SMC: comparar dos estrategias de búsqueda bibliográfica, una con asistencia IA y otra convencional, sobre una pregunta de música/sonido. Definir relevancia y exactitud de referencias, controlar consultas/tiempo y registrar decisiones. El equipo debe elegir y aprobar la pregunta y confirmar si este diseño cumple lo solicitado.

La tabla de bases de datos es de 2013/14: sirve como orientación docente, pero comprobar disponibilidad actual en biblioteca. Olsen y Denning están descargados como lecturas complementarias; no se atribuye aquí una síntesis no revisada de sus artículos.

Lecturas externas Introduction: Eco, O’Leary, PhD Comics, Frascati (principalmente cap. 2), Candler, Hong y Grossman. Para A1 solo se exige una de las dos opciones Eco/O’Leary y el formulario correspondiente.

Reality: Bruckman, Thomas Kuhn (Stanford y Naughton), código europeo de integridad, On Being a Scientist, código ACM, código UPF, etnocomputación, tecnologías disruptivas, indicadores RRI y base de retractaciones. Abrir la página Readings en el catálogo para los enlaces originales; algunos son históricos.

Information sources: Cornell sobre evaluación crítica, Olsen, Denning, Guzdial, código citable y GitHub para ciencia. El enlace Cornell visible en Moodle apunta erróneamente al antiguo Aula Global; localizar la lectura mediante biblioteca si hace falta.

La plantilla de formulación pide: tema/pregunta; metas e hipótesis; metodología y herramientas; fuentes y teorías; tareas y roles; fechas. Completar esos cinco bloques antes del pitch.

La plantilla Word pide abstract de 70–150 palabras, palabras clave, introducción, método, resultados, conclusiones y referencias. La plantilla sigue LNCS y muestra citas numéricas, mientras A3 recomienda APA 7: mantener APA 7 en A3 y confirmar el estilo final del paper con las docentes.
